# 기사 프로젝트 노트

기사 프로젝트 하나를 정리하는 한 장짜리 노트 페이지입니다.
HTML 파일 하나로 되어 있고, 설치나 서버 없이 브라우저에서 바로 열립니다.

## 들어 있는 칸

| 칸 | 설명 |
|---|---|
| 프로젝트 한 줄 | 프로젝트를 한 줄로 적는 칸 |
| 대주제 | 기사의 큰 주제 (예: 경제) |
| 할 일 체크리스트 | 5개, 체크하면 줄이 그어짐 |
| 날짜별 기록 | 세로선 위에 날짜 점이 찍히는 타임라인. 11/18부터 시작하고 "+ 다음 날 추가"로 하루씩 늘림 |
| 뉴스 애니메이션 | 상단 카드. 대주제에 맞춰 그림과 색이 바뀜 |

개인정보(전화번호, 주소 등)를 적는 칸은 없습니다.

## 사용법

1. `index_날짜.html` 파일을 브라우저(PC·휴대폰)에서 엽니다.
2. 글자를 눌러 바로 수정합니다.
3. 수정한 내용은 그 기기의 브라우저(localStorage)에 자동 저장됩니다.

> 저장은 기기·브라우저별로 따로 됩니다. 다른 기기에서 열면 내용이 비어 있습니다.

## 대주제별 애니메이션

대주제 칸에 아래 말이 들어 있으면 그림과 색이 바뀝니다.

| 대주제에 들어간 말 | 그림 |
|---|---|
| 경제, 금융, 주식, 금리, 부동산 | 오르는 그래프 |
| 정치, 국회, 선거 | 국회 건물 |
| 국제, 세계, 외교 | 지구본 |
| 사회, 교육, 노동, 복지 | 사람들 |
| 과학, 기술, AI, 반도체 | 칩 |
| 스포츠, 축구, 야구 | 공 |
| 문화, 연예, 영화, 음악 | 음표 |
| 환경, 기후, 에너지 | 나뭇잎 |
| 건강, 의료 | 심전도 선 |
| 그 외 | 물결 |

기기에서 "동작 줄이기"를 켜 두면 애니메이션 없이 정지된 모양으로 보입니다.

## 파일 이름

HTML 파일은 `index_만든날짜.html` 형식으로 저장합니다. (예: `index_20261118.html`)

## GitHub Pages로 열기 (선택)

GitHub Pages는 `index.html`이라는 이름을 기본 페이지로 찾습니다.
Pages로 공개하려면 파일 이름을 `index.html`로 바꿔 올리세요.

## 구성

- HTML, CSS, JavaScript만 사용 (외부 라이브러리 없음)
- 휴대폰 화면에 맞는 반응형 레이아웃
